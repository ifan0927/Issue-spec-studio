# Agent Bootstrap

1. Read `START_HERE.md` first. Do not recursively load every file in `docs/`, `templates/`, or a target repository.
2. Follow the load triggers in `START_HERE.md` and read only the references needed for the current task.
3. This repository stores only the approved Studio methodology, templates, guidance, and artifact contracts. Never store a target project's current state here.
4. Obtain human approval before changing the product boundary, canonical information model, authority hierarchy, or coding-ready gate.
5. Target-project design sessions run in the target repository. Any active checkpoint is project-owned, minimal, and temporary.
6. Never create a project registry, selected-project workspace, live Project Profile, active checkpoint, roadmap mirror, or issue mirror in this repository.
7. Use temporary directories outside the repository for disposable maintenance state.
8. Do not create a CLI, service, database, TUI, renderer framework, or platform integration without implementation authorization.

## Collaboration and validation

- Discuss with the user in Traditional Chinese; preserve English technical documentation unless an artifact explicitly requires another language.
- Respect the requested research, review, design, or implementation mode. Continue authorized work through verification and requested delivery.
- Treat an explicit user decision or authorization already given in the task as satisfying the corresponding approval requirement. Ask only about new decisions that materially change scope, product boundaries, authority, or the coding-ready gate; continue independent work while waiting.
- Skills and templates support the user's task; they do not silently expand it. If a rule blocks progress, cite the exact instruction and identify the concrete unresolved decision.
- Keep maintenance scoped and preserve unrelated changes. For Markdown-only work, check referenced paths, affected artifact contracts, and the final diff; do not scaffold or run application tests for this methodology repository.
